# Estimation Engine Validation

This document verifies the Pigmenta calculation engine by comparing manual mathematical estimations with the outputs generated by the React application logic.

Two standard validation cases cover:
1.  **Example 1**: Standard single room (walls + ceilings, standard paint, 2 coats).
2.  **Example 2**: Utility room (walls-only, budget paint, 2 coats).

---

## Example 1: Standard Single Room (4m × 5m × 2.4m)

### Setup Parameters
- **Dimensions:** Length = 4.0 m, Width = 5.0 m, Ceiling Height = 2.4 m
- **Selections:** Walls Painted = true, Ceilings Painted = true
- **Coats:** 2
- **Paint Quality:** Standard ($28.00 / L)

### Comparison Table

| Parameter | Manual Formula & Steps | Manual Value | App Engine Value | Status |
| :--- | :--- | :--- | :--- | :--- |
| **Wall Gross Area** | 2 × (4.0 + 5.0) × 2.4 | 43.20 m² | 43.20 m² | MATCH |
| **Ceiling Gross Area** | 4.0 × 5.0 | 20.00 m² | 20.00 m² | MATCH |
| **Paintable Area** | (43.20 × 2) + (20.00 × 2) | 126.40 m² | 126.40 m² | MATCH |
| **Raw Wall Paint** | 86.40 / 14 | 6.17 L | 6.17 L | MATCH |
| **Raw Ceiling Paint** | 40.00 / 14 | 2.86 L | 2.86 L | MATCH |
| **Wall Tins** | Best combo for 6.17L: 1 x 4L + 1 x 2L + 1 x 1L | 7.00 L | 7.00 L | MATCH |
| **Ceiling Tins** | Best combo for 2.86L: 1 x 2L + 1 x 1L | 3.00 L | 3.00 L | MATCH |
| **Total Purchased Paint**| 7.00L + 3.00L | 10.00 L | 10.00 L | MATCH |
| **Total Paint Cost** | 10.00L × $28.00/L | $280.00 | $280.00 | MATCH |
| **Labour Hours** | (86.40 / 10) + (40.00 / 7) ≈ 8.64 + 5.7143 | 14.35 hours | 14.35 hours | MATCH |
| **Labour Cost** | 14.3543 hours × $65.00/hour | $933.03 | $933.03 | MATCH |
| **Total Room Estimate** | $280.00 (Paint) + $933.03 (Labour) | $1,213.03 | $1,213.03 | MATCH |
